# SISTEMAS-EXPERTOS

## Contenido:

### En el siguiente repositorio se muestra la creación de un Knowledge graph sobre el dominio de "Mecánica Automotríz".
### Se utilizó Obsidian para la elaboración del proyecto.


## Estructura de Archivos
* `MOC Mecanica Automotriz.md`: Nota raíz que engloba y organiza todo el dominio.
* `/Componentes`: Notas individuales con la descripción y fallas de las piezas físicas.
* `/Sintomas`: Notas individuales que simulan las entradas o consultas que un usuario haría al sistema experto.
